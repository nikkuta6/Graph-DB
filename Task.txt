Тема: Графовая база данных для управления проектами

Предметная область:
ИТ и разработка. Управление проектами: задачи, исполнители, баги и блокирующие связи.

Необходимо разработать графовую базу данных в MS SQL Server, которая описывает связи между задачами проекта, исполнителями и багами.

В базе данных должны быть представлены следующие типы узлов:
1. Executor — исполнитель.
2. ProjectTask — задача проекта.
3. Bug — баг.

В базе данных должны быть представлены следующие типы рёбер:
1. AssignedTo — задача назначена исполнителю.
2. Reported — исполнитель сообщил о баге.
3. BugBlocksTask — баг блокирует задачу.
4. TaskBlocksTask — одна задача блокирует другую задачу.

Необходимо:
1. Создать таблицы узлов и рёбер средствами SQL Server Graph.
2. Добавить ограничения CONNECTION для таблиц рёбер.
3. Заполнить каждую таблицу узлов минимум 10 строками.
4. Заполнить таблицы рёбер.
5. Выполнить минимум 5 запросов MATCH с цепочкой из трёх и более узлов.
6. Выполнить минимум 2 запроса SHORTEST_PATH.
7. Подготовить диаграммы узлов и рёбер в draw.io.
8. Визуализировать граф в Power BI с помощью Force-Directed Graph.
9. Предложить новую задачу для графовой базы данных.
