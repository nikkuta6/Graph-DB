Тема: Графовая база данных для системы рекомендаций учебных курсов

Описание задачи: Необходимо разработать графовую базу данных для анализа связей между студентами, учебными курсами, преподавателями и навыками. Такая база данных может использоваться для построения рекомендаций: какие курсы стоит пройти студенту, какие навыки развивает курс и какие преподаватели ведут связанные дисциплины.

Возможные таблицы узлов:

Student — студент.
Course — учебный курс.
Teacher — преподаватель.
Skill — навык.

Возможные таблицы рёбер:

EnrolledIn — студент записан на курс.
Completed — студент завершил курс.
Teaches — преподаватель ведёт курс.
RequiresSkill — курс требует определённый навык.
DevelopsSkill — курс развивает определённый навык.
SimilarTo — один курс похож на другой.

Примеры возможных запросов:

Найти курсы, которые подходят студенту на основе уже полученных навыков.
Найти кратчайший путь от текущих знаний студента до нужного профессионального навыка.
Найти преподавателей, которые ведут курсы, развивающие выбранный навык.
Найти студентов с похожими образовательными траекториями.
Найти цепочку курсов от начального уровня до продвинутого.

Почему задача подходит для графовой базы данных: Данные имеют большое количество связей: студенты связаны с курсами, курсы связаны с навыками, преподаватели связаны с курсами, а сами курсы могут быть связаны между собой. Графовая модель позволяет удобно анализировать такие связи, искать пути между объектами и строить рекомендации.
